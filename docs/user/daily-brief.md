# Daily brief

Open **Today** from the sidebar for a morning brief: the one thing to push forward, your top
to-dos, what changed since the last brief, and today's meetings.

Claude writes it with your claude.ai connectors. It reads your Jira issues, your pull requests,
Slack messages that involve you, and recent Gmail, including calendar invitations. If the Google
Calendar connector is connected in claude.ai, it reads today's events from there too. The brief
only reads; it never sends, posts or changes anything.

## Set it up

1. Make sure Claude Code is signed in on this machine and that Slack, Gmail and Atlassian are
   connected in your claude.ai settings.
2. In **Settings → Integrations → Daily brief**, choose the time and language. Under **What to
   watch**, name the channels, people or projects that matter most.

The brief is written at that time while Naowee Code is open, or when it next opens that day.
**Write now**, or the refresh button on the Today page, writes it again on demand. Each brief
takes a minute or two and uses your Claude plan.

**Let's do it** and **Prep me** start a thread in the project you choose, with the task or the
meeting already in the composer. Check off to-dos as you go; the checks stay on this device.

The painting each day comes from the public-domain collection of the Art Institute of Chicago.
